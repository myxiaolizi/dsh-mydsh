# 我的 DSH

一个插件管住 DeepSeek Harness 的常用调整。装这一个，不用再为每项能力单独装插件。

## 它能做什么

**界面与入口，全部可配**

- 隐藏「新会话」按钮、侧栏的 `deepseek HARNESS` 图标与文字（图标和文字分开控制）
- 把侧栏底部的用户区移到标题栏，只显示头像，点击展开设置与反馈
- 点击侧栏的「工作区 / 会话」按钮直接切换下方列表分组
- 每个入口是否出现都单独可控：侧栏面板图标、侧栏底部用量条、设置页分页、标签栏的上下文/编队/用量、输入框的续跑方式、输入区状态栏的极客指标与本会话消耗、标题栏上下文胶囊
- 开关立即生效，不需要刷新页面，也不需要重启

**用量与计费**

- 按时间、会话、工作区、供应商、模型五个维度统计 token：总量、输入、输出、缓存读、请求数、时长、预估费用
- 六种区间：今日、近 3 天、近 7 天、近 1 月、近 3 月、自定义
- 趋势图、活动热力图、按小时/按天的分布
- 上下文洞察：窗口占用、七类构成（系统提示词/工具定义/用户消息/注入内容/技能注入/助手消息/工具结果）、随轮演变、可下钻的明细
- 余额查询：DeepSeek 官方余额，以及其他供应商的自定义接口
- 分维度预算（全局/供应商/模型/工作区 × 每天/每周/每月）：到阈值提醒，超限可暂停任务
- 内置价目表估算费用；查不到价格的模型标为「估算」而不是假装准确，你也可以自己填覆盖价

**备份**

- 七类内容：工作区文件、上下文对话、系统配置、插件及配置、模型与供应商、其他、凭据
- 五种存放位置：本地目录、WebDAV、阿里云 OSS、S3 兼容、GitHub Gist
- 五种触发：每天定时、每周定时、固定间隔、启动时、每次会话完成后，也可手动
- 全量与增量；zip / 7z；AES-256-GCM 加密；按大小分卷；按份数保留
- 恢复解包到独立目录，绝不覆盖正在运行的会话与配置

**重试与故障切换**

- 按状态码、错误码或兜底匹配；每条规则决定重试、切到下一路线、还是直接失败
- 固定或指数退避，可遵守服务端 `Retry-After`
- 可切模型、可切供应商，带单次请求切换上限与路由顺序
- 设置页可以先用一个合成失败试跑规则，看到「现在遇到 429 会发生什么」再保存

**个性化**（原「系统提示词」）

- 称呼、助手名字、回复风格、长期指令、人设设定
- 全局生效，或只在指定工作区（含子目录）生效
- 长期记忆：手动或沉淀的条目，按关键词与时间做确定性召回，不调用额外的模型
- 行为纪律：模型声称完成但没有工具调用、没有可核对的证据，或同一工具连续失败时给出纠偏提示

**能力模块**

- 极客请求指标、上下文洞察、余额、用量聚合、长期记忆、行为纪律、桌面自动化、MCP 连接、配置管理、技能中心、角色专家、图像生成、编队视图
- 每项独立启停；高风险项首次启用需要二次确认；当前环境不支持的项目会写明原因而不是静默失效

**远程访问**

- 插件以出站连接连到你自建的中转服务端，本机不需要开放端口
- 注册、登录、连接状态、公网地址、流量统计可见
- 中转服务端随包提供，零第三方依赖，含宝塔部署步骤

## 安装

1. 打开 **设置 → 插件 → 添加插件**，选择本目录（或把打包好的 zip 交给它）。
2. 装好后在 **设置** 里会出现「我的 DSH」分页。
3. 需要侧栏图标或标签页时，到「界面」分页把对应入口打开。

所有开关默认是保守的：会改动界面的、会联网的、会放宽权限的，默认都关着。

## 数据放在哪

`<DSH_HOME>/dsh-mydsh/` 下，一个 `settings.json` 加各引擎自己的子目录（备份历史、恢复目录、通知、截图、生成的图片）。插件不会改写你的 `cordis.patch.yml`，所以升级或重装都不会覆盖你自己的配置。

## 已知边界

- 备份恢复只解包到独立目录，不直接替换正在运行的数据；确认内容后再由你手动搬过去。
- 余额查询只对填了接口的供应商生效；没有余额接口的供应商用价目表估算费用。
- 浏览器实时投屏（接管真实浏览器）没有实现：它需要独立的 Chromium 通道，风险与体积都不适合放进这个插件。设置页会如实标注不可用。
- 桌面自动化只在 Windows 上可用，且每个动作都按开关与二次确认放行。
- 远程访问依赖你自己部署的中转服务端；插件本身不把任何数据发给第三方。
- 编队视图读取 DSH 内置的编队与子代理数据，只读展示，不自建第二套运行时。
