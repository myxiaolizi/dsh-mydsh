# 我的 DSH 能做什么

设置页共九个分页：总览、界面、用量与计费、备份、重试、个性化、能力模块、远程访问、关于。除「总览」与「关于」外，其余分页都可以在「界面」里隐藏。

## 总览

一眼看清两件事：有没有东西在报警，以及最近花了多少。上排是区间用量卡片与趋势，右侧是各子系统状态（用量统计、备份、重试、个性化、远程访问），下方是能力模块的启用情况和三个快捷动作。

## 界面

三类设置：

1. **品牌与外壳** —— 隐藏新会话按钮、侧栏图标、侧栏文字（图标与文字分开）、侧栏折叠按钮；把侧栏底部的用户区移到标题栏并只留头像。
2. **列表与密度** —— 点击侧栏的「工作区 / 会话」按钮是否切换下方分组、默认分组方式、三档密度。
3. **功能入口** —— 每一项入口是否出现。关掉的入口不注册任何组件，因此不产生渲染、订阅或轮询开销。

## 用量与计费

- **本期看板**：选区间后显示请求数、总 token、输入、输出、缓存命中率、token 速度，配趋势图、热力图和四维排行（供应商 / 模型 / 工作区 / 会话）。点任意一行可以下钻。
- **极客请求指标**：首字时间、解码速度、token 数。输入区状态栏那颗胶囊点开就是最近若干次请求的明细表。
- **上下文洞察**：窗口占用与七类构成，随轮演变的趋势，以及可逐项钻取的明细。
- **余额**：DeepSeek 官方接口，或其他供应商的自定义 HTTP 接口（用点路径从返回 JSON 里取总额与币种）。
- **预算**：按范围与周期设上限，到 90% 提醒，超限可以只提醒或暂停任务。暂停的实现是拒绝下一次模型请求并把原因说清楚，不会把正在生成的回答砍断。
- **价目表**：内置主流模型价格；你自己的模型可以填覆盖价，覆盖价的来源标记为 `override`。

## 备份

上方是状态条（是否在跑、7z 是否可用、上次备份时间、本次估算大小），下面是四个区块：

- **内容**：七类可勾选项。凭据类只有开启加密后才会被收录，否则会被拒绝并说明原因。
- **存放位置**：可以配置多个目标，选其中一个作为当前目标。每个目标都能单独测试连通性。
- **触发方式**：每天、每周、固定间隔、启动时、会话结束后，也可以只手动。
- **类型与压缩**：全量或增量；zip / 7z / 不压缩；分卷大小；保留份数；单文件大小上限。
- **加密**：AES-256-GCM，密码错或文件被改都会明确报错。
- **跨机同步**：与目标上的备份索引对齐，冲突按「较新 / 本地 / 远端」决策。
- **历史**：每次运行的结果，失败的会标红并给出原因。

## 重试

- 规则表：按状态码或错误码匹配，选重试、切路线或直接失败；可设最大次数、间隔、退避方式。
- 切换顺序：失败时按列表依次尝试 provider / model。
- 试跑：不等到真出错，直接用一个合成失败看规则会怎么判。
- 运行记录：最近的尝试、重试、切换与失败计数。

## 个性化

称呼、助手名字、回复风格、长期指令、人设设定、生效范围，加两块子功能：

- **长期记忆**：条目的增删改与置顶，按关键词和时间的确定性打分召回，不额外调用模型。
- **行为纪律**：三种纠偏——声称完成却没有动作、声称完成却没有可核对的证据、同一工具连续失败。

右侧可以实时预览最终会注入什么，以及当前会话是否真的会附加内容。

## 能力模块

十四张卡片，每张写明它做什么、风险等级、以及当前环境是否可用。高风险项首次开启需要二次确认。展开后是该模块自己的设置：桌面自动化的四项能力开关、MCP 服务器列表与连通测试、图像生成的接口与尺寸、角色专家的自定义条目、配置管理的读写权限、技能与编队的只读视图。

## 远程访问

填中转服务端地址，注册或登录账号，然后连接。连上以后这里会显示公网地址、上下行流量与请求数。服务端要你自己部署（随包提供了宝塔部署步骤），插件不会把数据转发给任何第三方。
